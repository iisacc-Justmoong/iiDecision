# 확률 모델과 정밀도 정책

iiDecision의 우선순위는 **수학적 계약의 명료성 → 수치 안정성 → 검증 가능성 → 속도**이다.
빠른 직관적 판단을 제품 목표로 삼는 Jev에서 구조화된 확률 반환을 참고하되,
iiDecision은 입력된 확률 모델을 정밀하게 계산하는 목적을 명시적으로 가진다.
응답 시간 목표나 근사 추론을 기본 동작으로 두지 않는다.

## 유한 결합 모델

호출자는 서로 배타적인 후보 C와 관측 변수 X의 유한 결합 상태를 제공한다.
각 상태 s의 질량은 `w(s) = exp(log_weight(s))`이다. 정규화 상수를 Z라 하면
`P(s) = w(s) / Z`이다. 여러 관측 E가 주어지면 다음 값을 전수 합산한다.

```
P(C=c | E) = sum(w(s), s satisfies E and C=c) / sum(w(s), s satisfies E)
P(E)       = sum(w(s), s satisfies E) / sum(w(s), all s)
H(C | E)   = -sum(P(c | E) * ln(P(c | E)), all c)
```

관측 사이의 독립성을 가정하지 않는다. 상관관계는 결합 상태의 가중치에 표현된다.
유한 모델의 모든 선언된 상태를 계산하므로 Monte Carlo 오차, beam pruning,
상위 후보 절단은 없다. 표에 생략된 조합은 확률 0이다. 모델 전체가 현실을
충분히 표현하는지는 호출자의 모델링과 별도 평가로 확인해야 한다.

입력 질량이 이미 정규화되어 있을 필요는 없다. 최대 확률 선택은 가장 가능성이
높은 대안의 선택이다. 비용이나 행동 결과의 최대 기대 효용 계산과는 다른 목적이다.
두 목적을 같은 probability 필드로 혼합하지 않는다.

## 수치 연산

- `long double`과 자연로그를 사용한다. `probability_mantissa_bits`는 실제 가수
  비트 수이다. macOS arm64에서는 보통 double과 같은 53비트이며 이 검증에서도
  실제 값을 기록한다. 타입 이름만으로 더 높은 정밀도를 주장하지 않는다.
- 최대 로그 가중치를 기준으로 이동하고, 선두 항의 1을 분리한 `log1p`와
  Neumaier 보상 합산을 사용한다. 합산 순서를 정렬하여 모델 행 순서에 의존하는
  반올림 차이를 줄이고 동일 환경에서 재현한다.
- 조건부 확률은 일치 상태 안에서 다시 기준값을 잡는다. 전체 분포에서 매우 드문
  증거가 선형 underflow하더라도 조건부 분포 계산에 그 0을 사용하지 않는다.
- 확률과 로그 확률을 함께 보존한다. 선형 확률이 숫자 표현 범위 밖이라 0이 된
  경우와 모델에서 선언한 확률 0을 구분하며 `underflowed_candidates`를 보고한다.
- `normalization_error = abs(sum(probability) - 1)`를 보고한다. 이는 정규화 잔차이며
  모든 계산의 오차 상한이나 모델의 정답률을 의미하지 않는다.
- 부동소수점 범위를 벗어난 연산은 명시적으로 실패한다. fast-math와 부동소수점
  contraction을 라이브러리 빌드에서 비활성화한다. 플랫폼 간 비트 단위 일치는
  계약에 포함하지 않는다.

정확한 유한 상태 추론과 정확한 실수 산술은 구분한다. 임의 정밀도나 엄밀한
구간 오차 경계를 제공하는 구현은 아니다. 현재 정확성의 증거는 수학적 기준값,
경계 테스트와 90자리 Decimal 기반의 독립 검증이다.

## 예측 품질 평가

- 정확도: 선택 후보와 정답이 일치한 사례의 비율이다.
- Log loss: `-ln(P(target))`의 평균이다. 유한 로그 확률을 직접 사용하므로
  선형 underflow로 무한대가 되는 오류를 피한다. 구조적 0만 무한대이다.
- Multiclass Brier: 사례별 `sum((P(c) - 1[c=target])^2)`의 평균이다.
  클래스 수로 나누지 않으며 범위는 0~2이다.
- Reliability bins: 선택한 후보의 확률을 0~1의 동일 폭 구간에 넣고, 각 구간의
  사례 수·평균 선택 확률·실제 정확도를 반환한다. 1은 마지막 구간에 속한다.
- ECE: 각 구간에서 평균 선택 확률과 정확도의 차이에 사례 비율을 곱한 합이다.
  구간 수와 표본 수에 영향을 받는다. 빈 구간의 count는 0으로 유지한다.

엔트로피는 분포의 불확실성이다. Brier와 log loss는 calibration 외에 판별력도
반영하므로 하나의 숫자만으로 calibration을 입증하지 않는다. Reliability와
ECE는 정답이 있는 독립 평가 데이터에서 함께 해석한다. 예제와 수치 검증의
합성 데이터는 실제 제품의 예측 정확성 증거로 사용하지 않는다.
